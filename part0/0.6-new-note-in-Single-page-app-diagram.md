# Exercise 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User wrote a note FullStackOpen and clicks Save
    Note right of browser: Browser executes JS that prevents default form submit (e.preventDefault)
    Note right of browser: JS adds the new note to its local notes array
    Note right of browser: JS re-renders the notes list on the page (no reload)

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note right of server: Server saves the note
    server-->>browser: 201 Created {"content": "FullStackOpen","date": "2026-08-11T09:37:10.030Z"}
    deactivate server

    Note right of browser: Browser stays on the same page, no reload
```
